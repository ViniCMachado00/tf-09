1. Encapsulamento
É proteger os dados de um objeto para que não sejam alterados de qualquer jeito.

2. Herança
É quando uma classe aproveita características e comportamentos de outra classe, evitando repetir código.

3. Polimorfismo
É quando objetos diferentes podem responder à mesma chamada de maneiras diferentes.

4. Interface
É um contrato que diz quais operações uma classe precisa oferecer, sem determinar necessariamente como elas serão realizadas.

5. Implementação
É o código que faz a operação funcionar. Ela contém os detalhes internos que quem usa o objeto não precisa conhecer.
